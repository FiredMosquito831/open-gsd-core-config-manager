Frozen existing routes from 02-API-CONTRACT.md:
- GET /api/configs -> { ok: true, configs: TrackedConfig[] }
- POST /api/configs/track -> validates a raw absolute .json path through registry.track()
- GET /api/configs/:id -> resolves opaque id, returns LoadResult unchanged
- PUT /api/configs/:id -> resolves opaque id, calls saveWithSnapshot, ignores any body.path

New additive route contract to implement:
- GET /api/schema -> { ok: true, schema: Record<string, SchemaEntry> }
- GET /api/workspace/configs -> { ok: true, configs: TrackedWorkspaceConfig[] }
- POST /api/workspace/configs/track -> { path } -> registry.track(path) -> persist -> { ok: true, config }
- DELETE /api/workspace/configs/:id -> persist removal; does not delete the config file
- POST /api/workspace/configs/reorder -> { ids } -> persist order after validating known ids
- POST /api/workspace/configs/:id/locate -> { path } -> registry.track(path) -> replace persisted entry
- POST /api/workspace/scan -> { rootPath } -> returns candidates only; never tracks without confirmation
- POST /api/workspace/configs/create-preview -> { projectDir } -> server-computed target path and existence status
- POST /api/workspace/configs/create -> { projectDir, overwrite } -> create <project>/.planning/config.json through saveWithSnapshot and persist/track it
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to /api/workspace | Client-supplied path strings enter server-owned filesystem logic. |
| App-data store to registry | Persisted paths are replayed into runtime registry on launch. |
| Scanner to filesystem | Recursive traversal touches user-selected directories. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Elevation of Privilege | workspace track/locate/create routes | high | mitigate | All concrete config paths go through registry.track() or a server-computed target; no save route accepts body.path. |
| T-03-05 | Information Disclosure | workspace route errors | medium | mitigate | Reject with fixed static messages; never echo rejected path values in ApiErr. |
| T-03-06 | Denial of Service | folder scan | medium | mitigate | Skip .git/node_modules/dist, bound traversal to the chosen root, and return candidates only. |
| T-03-07 | Tampering | workspace-store replay | medium | mitigate | Persist minimal path/order metadata; validate/reclassify status at startup before presenting to UI. |
</threat_model>
