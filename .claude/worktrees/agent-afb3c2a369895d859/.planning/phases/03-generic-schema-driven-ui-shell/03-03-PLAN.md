## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser API client to Fastify /api | Token-bearing client requests cross into guarded local server routes. |
| Raw loaded project JSON to form state | Unknown/future keys must remain data, not executable content or dropped fields. |
| Schema metadata to browser validation | Server schema is rendered/compiled in the browser. |
