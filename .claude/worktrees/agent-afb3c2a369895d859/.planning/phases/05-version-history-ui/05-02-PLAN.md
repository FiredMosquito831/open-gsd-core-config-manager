<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser params → history routes | ID and sequence are attacker-controlled. |
| Registry → filesystem | Only a server-minted opaque ID may resolve to a tracked path. |
| Snapshot index → content read | Local app-data index/file can be malformed or tampered. |
| Snapshot document → config write | Historical JSON is untrusted until parsed and validated. |
