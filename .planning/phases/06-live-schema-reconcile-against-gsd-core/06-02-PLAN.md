<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parsed upstream evidence → canonical candidate | Untrusted structural/documentation values enter descriptor construction. |
| Trusted local builder → shared reconciler | Local module execution must not leak into the remote path. |
| Active curated schema → proposed schema | User-authored product documentation and specialized metadata must survive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-02-01 | Tampering | reconcileSchemaSources | high | mitigate | Apply structural extraction first, curated and specialized overlays last, with regression fixtures for every protected field. |
| T-06-02-02 | Elevation of Privilege | build-schema adapter | critical | mitigate | Keep createRequire in the trusted-local adapter only; pure reconciler accepts data objects and has a negative import audit. |
| T-06-02-03 | Spoofing | bundled identity | high | mitigate | Validate stable semver/tag and require immutable identity fields when known; never synthesize evidence. |
| T-06-02-04 | Information Disclosure | change evidence | medium | mitigate | Emit normalized values/fingerprints only, never filesystem paths or raw parser internals. |
| T-06-02-05 | Denial of Service | nested descriptor normalization | medium | mitigate | Bound recursion/depth in source contracts and reject unsafe/prototype path segments. |
| T-06-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no package; archive dependency remains gated by 06-01. |
</threat_model>
