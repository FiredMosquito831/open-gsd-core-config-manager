<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server-normalized evidence → DOM | Remote-derived values are displayed to the user. |
| User action → lifecycle API | Explicit activation/reset must not be confused with review/check actions. |
| Mutation success → client caches | Old config/schema caches could create split generations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-07-01 | Tampering | client lifecycle calls | high | mitigate | Typed wrappers send no upstream selectors/schema body; activation uses opaque id only. |
| T-06-07-02 | Spoofing | proposal active status | high | mitigate | Explicit `Review required — not active`, separate Activate action, active card unchanged until server success. |
| T-06-07-03 | Information Disclosure | evidence/error rendering | high | mitigate | Render normalized allowlisted DTO fields and static copy only; negative sentinel tests prevent raw URLs/paths/errors. |
| T-06-07-04 | Tampering | cache transition | critical | mitigate | Await schema and active-config invalidation/refetch before editor resume; integration assertion verifies ordering. |
| T-06-07-05 | Elevation of Privilege | reset/activate controls | medium | mitigate | Existing authenticated apiFetch boundary, server authority, explicit review/reset dialog, disabled duplicate actions. |
| T-06-07-06 | Denial of Service | many-change rendering | medium | mitigate | Filtered grouped rendering, bounded evidence overflow, many-key backstop, no unbounded animation. |
| T-06-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No UI package or registry dependency is added. |
</threat_model>
