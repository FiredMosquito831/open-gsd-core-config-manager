<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → guarded local API | Any web page may attempt local refresh/activation/reset. |
| Opaque proposal id → server-held candidate | Client asks for a state transition but must not supply content. |
| Manager snapshot → config/history operations | Validation and rendering must share one generation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05-01 | Elevation of Privilege | schema lifecycle routes | critical | mitigate | Register only in existing Host/Origin/token-guarded /api scope and test every guard. |
| T-06-05-02 | Tampering | refresh/activate input | critical | mitigate | Empty refresh contract, opaque-id-only activation, reject additional selectors/schema payloads. |
| T-06-05-03 | Tampering | config/history validation | critical | mitigate | Capture one manager snapshot per operation and route schema+validator together. |
| T-06-05-04 | Repudiation | activation identity | high | mitigate | Return/record proposal and active immutable identity/timestamps through typed status. |
| T-06-05-05 | Information Disclosure | API errors/status | high | mitigate | Static error allowlist and sentinel negative tests for paths, URLs, archive names, source, raw exceptions. |
