<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API → release identity | Untrusted network JSON claims stable release and tag identity. |
| Proven inert parsed sources → reconciliation | Bounded data and documentation fingerprints cross into candidate construction. |
| Compiled candidate → proposal store | Candidate may become activatable later but must remain inert and server-held now. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06-01 | Spoofing | release/tag resolver | critical | mitigate | Fixed official repository/latest endpoint, stable-release validation, bounded tag-to-commit dereference, commit-pinned fetch, and identity cross-check. |
| T-06-06-02 | Tampering | parsed source evidence | critical | mitigate | Consume only 06-05 parsers, require all sources, preserve per-key evidence integrity, reconcile and compile before proposal retention. |
| T-06-06-03 | Tampering | documentation evidence | high | mitigate | Pass only deterministic fingerprints/diagnostics; retain curated prose; end-to-end one-prose-section/one-note test. |
| T-06-06-04 | Spoofing | same-version identity | high | mitigate | Treat different immutable commit/archive identity at equal semver as conflict with no proposal or activation. |
| T-06-06-05 | Information Disclosure | refresh errors | high | mitigate | Enumerated static path/URL/archive/source/raw-error-free responses; raw diagnostics remain server-side without source bodies. |
| T-06-06-06 | Tampering | proposal lifecycle | high | mitigate | Opaque expiring in-memory proposal, single flight, compile gate, cancellation/supersession invalidation, and no manager activation call. |
| T-06-06-07 | Denial of Service | network and staged transaction | high | mitigate | Bounded dereference, fetch/parse timeouts inherited from archive limits, single flight, and source-byte release. |
| T-06-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install occurs here; 06-05 already enforced the 06-01 decision and official-format compatibility gate. |
