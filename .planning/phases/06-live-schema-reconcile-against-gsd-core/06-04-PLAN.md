<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API → release identity | Untrusted network JSON claims stable release and tag identity. |
| Pinned archive bytes → parser | Compressed hostile data crosses memory/resource and path boundaries. |
| CommonJS text → schema evidence | Executable syntax must be treated solely as inert AST data. |
| Parsed evidence → proposal | Malformed or inconsistent values must never become activatable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04-01 | Spoofing | release/tag resolver | critical | mitigate | Fixed official repository/latest endpoint, stable-release validation, tag-to-commit dereference, commit-pinned fetch, identity cross-check. |
| T-06-04-02 | Tampering | archive/source content | critical | mitigate | SHA-256 provenance, exact allowlist, duplicate/missing rejection, JSON/AST/schema validation. |
