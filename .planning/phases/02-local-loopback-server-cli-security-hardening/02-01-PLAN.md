  <action>
    Create `test/server/helpers/spawn-cli.ts` exporting two things.

    First, a **pure** exported function `parseBannerUrl(chunk: string): { url: string; port: number; token: string } | null`. It scans a stdout chunk for the launch-banner URL and extracts the port and token. The banner URL format is frozen by 02-UI-SPEC.md as `http://127.0.0.1:<port>/?t=<token>` where the token is a `crypto.randomUUID()` (36 chars, lowercase hex + hyphens). Match on that shape; return `null` when the chunk contains no banner URL. Keeping this pure is what makes the harness itself unit-testable without spawning anything.

    Second, an async exported function `spawnCli(args: string[], opts?: { cwd?: string; env?: NodeJS.ProcessEnv; timeoutMs?: number }): Promise<SpawnedCli>` where `SpawnedCli` is `{ proc: ChildProcess; port: number; token: string; url: string; stdout: () => string; stderr: () => string; exited: Promise<{ code: number | null; signal: NodeJS.Signals | null }>; kill: (signal?: NodeJS.Signals) => void }`.

    `spawnCli` spawns the CLI **from source via tsx** — `node_modules/.bin/tsx` (resolve it cross-platform; on Windows the `.cmd` shim requires `shell: true` or resolving `tsx.cmd`, so prefer spawning the current `process.execPath` with the tsx CLI entry resolved from `node_modules/tsx/dist/cli.mjs` to stay shell-free and Windows-safe) against `packages/cli/src/cli.ts`, forwarding `args`. It must NOT depend on a build step — Plan 07 separately smoke-tests the built `dist/cli.js`.

    It accumulates stdout/stderr into buffers, resolves as soon as `parseBannerUrl` matches a stdout chunk, and rejects with the accumulated stderr if the process exits first or if `timeoutMs` (default 20000) elapses. It sets `stdio: ['ignore', 'pipe', 'pipe']` and passes `env: { ...process.env, NO_COLOR: '1', ...opts?.env }` so output is always the plain ASCII form (02-UI-SPEC.md degrade rule) and the parser never has to strip ANSI escapes.

    `exited` is a promise that resolves with the child's exit code and signal; `kill(signal = 'SIGINT')` forwards the signal to the child. Both exist so Plan 06's teardown test can assert clean exit.

    Then create `test/server/helpers/spawn-cli.test.ts` with a `describe` block covering `parseBannerUrl` only (no spawning — the CLI does not exist yet and this file must stay green from the moment it is written). Cover: (a) a realistic multi-line plain-mode banner chunk yields the right port and token; (b) a chunk with unrelated log noise yields `null`; (c) a chunk containing a URL with a non-loopback host does not match.
  </action>
