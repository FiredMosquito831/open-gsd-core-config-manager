  <action>
    Create `packages/cli/src/bootstrap.ts` exporting `bootstrap(opts, deps?)` and `registerSignalHandlers(handle, deps?)`.

    `bootstrap(opts: { port?: number; open: boolean }, deps?: { open?: (url: string) => Promise<unknown>; out?: OutputPort; clientRoot?: string })` returns `{ app, url, port, token, ctx, shutdown }` and performs, in order:
    1. `createLaunchContext()` — mints the per-launch token with `crypto.randomUUID()` (D-05). Never hand-roll random-token generation.
    2. `buildApp({ ctx, clientRoot })` where `clientRoot` defaults to the `dist/client` directory resolved relative to the running module.
    3. `await app.listen({ port: opts.port ?? 0, host: '127.0.0.1' })` — D-02: port 0 lets the OS assign a free ephemeral port, which is why no `get-port` dependency and no `EADDRINUSE` collision handling exist. The host is the literal loopback address and there is no flag or env var that can change it — binding any other interface would expose the user's config to the LAN.
    4. Read the assigned port back from `app.server.address()` (cast to `AddressInfo`).
    5. `sealLaunchContext(ctx, port)` — fills `allowedHosts` and `corsOrigin` from the now-known port. This must happen before any request can arrive; until it runs the guards fail closed. Requests cannot arrive before `listen()` resolves, so this ordering is safe and is the answer to 02-RESEARCH.md Pattern 3's "origin is a runtime value" gotcha.
    6. Build the URL as `http://127.0.0.1:<port>/?t=<token>` and print the banner via `out.banner(url)`.
    7. If `opts.open` is true, `await deps.open?.(url)` (defaulting to the real `open` package, which is ESM-only). Wrap it in its own try/catch: a headless box, WSL without interop, or no default browser must NOT kill the server — catch, print `out.openFailed(url)`, and continue serving. If `opts.open` is false, print `out.noOpenHint()`.
    8. Return the handle. `bootstrap` does **not** register signal handlers — that stays in `cli.ts` so in-process tests can call `bootstrap` without installing a process-wide handler per test.

    `shutdown()` on the returned handle: guard against re-entrancy with a flag, print `out.shuttingDown()`, arm an unref'd force-exit timer (5 seconds — generously above `close-with-grace`'s 500 ms default, which 02-RESEARCH.md flags as dangerously aggressive), then **`await app.close()`**, then clear the timer, then print `out.stopped()`. The await is not stylistic: a fire-and-forget `close()` lets `process.exit()` run before the socket is actually released, which is a documented Fastify bug (discussion #5140) and is precisely what the teardown suite's ECONNREFUSED probe catches. The confirmation line prints only after `close()` resolves, so the user is never told the port is free before it is. `fastify.close()` also runs the plugin close hooks, which is what drops any `proper-lockfile` lock still held by an in-flight save.

    `registerSignalHandlers(handle, deps?)` wires `SIGINT` and `SIGTERM` to `handle.shutdown()` followed by `process.exit(0)`, using `process.once` per signal so a double Ctrl-C cannot re-enter.

    Create `packages/cli/src/cli.ts`: the `bin` entry. First line is the shebang `#!/usr/bin/env node` (tsup preserves it and chmods the output; CLAUDE.md forbids `pkg`/SEA). Define the Commander program named `gsd-config-manager` with `--port <number>` (parsed as a base-10 integer; reject a non-numeric or out-of-range value with the startup-error copy and exit 1) and `--no-open` (Commander's negatable-boolean form: declaring `--no-open` alone makes `opts.open` default to `true` and become `false` only when the flag is passed — do not also declare a positive `--open`). Do not add `--scan` (see `<scope_note_cli_flags>`).

    Then call `bootstrap`, and on failure map the error to 02-UI-SPEC.md's copy: an `EADDRINUSE` (only reachable when `--port` was explicitly passed, since port 0 cannot collide) prints `out.portInUse(port)` and exits 1 with the banner never printed; any other startup failure prints `out.startupError(message)` and exits 1. On success, call `registerSignalHandlers`.

    Wire `out.warnLine` as the `warn` sink passed into the app so the D-12 snapshot warning reaches the terminal with the correct symbol and color treatment. (If Plan 05's `BuildAppOptions.warn` has not landed yet in your working tree, wire it as soon as it does — the option is optional, so this file compiles either way.)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Process → network interface | Which interface the socket binds decides whether the API is reachable only by this user, or by the whole LAN. |
| Launch token → terminal, browser URL, process environment | The token is minted here and is the only credential in the system. |
| Process lifecycle → OS resources (port, advisory locks) | An unclean exit leaves a bound port, an orphan process, or a stale lock that blocks the next save. |
| `open` package → OS default browser | An external process is launched with a URL containing the credential. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08 | Elevation of Privilege | `bootstrap.ts` `listen()` — binding `0.0.0.0` (or `::`), exposing the config read/write API to every machine on the network | critical | mitigate | The host is the hardcoded loopback literal `127.0.0.1`; there is no `--host` flag and no env override. Verified behaviorally by cli-launch.test.ts "binds only to the loopback interface" (asserts `server.address().address === '127.0.0.1'`) and by a comment-filtered source grep proving no wildcard address appears. |
| T-02-09 | Denial of Service | `shutdown()` — fire-and-forget `fastify.close()` leaving the port bound, an orphan process, or a held `proper-lockfile` lock that blocks the user's next save | medium | mitigate | `await app.close()` before `process.exit(0)`, re-entrancy flag, unref'd 5s force-exit safety net, and the confirmation printed only after close resolves. Verified: teardown.test.ts "SIGINT releases port and locks" (ECONNREFUSED probe), "SIGTERM also shuts down cleanly", "prints the shutdown confirmation only after the server has closed", "leaves no lock file behind". |
| T-02-28 | Spoofing | Weak or predictable launch token, letting another local process guess it and gain full config read/write | high | mitigate | `crypto.randomUUID()` (122 bits of CSPRNG entropy), minted once per process and never persisted to disk. No hand-rolled random-string generator. |
| T-02-04c | Information Disclosure | The tokenized URL leaking via the process argument list, an environment variable, or a shell history entry when handed to the `open` package | low | mitigate | The URL is passed as a function argument to `open`, which hands it to the platform opener; it is never written to an env var, never echoed through a shell, and never persisted. The terminal banner prints it by design (the user needs it), which is the accepted, intended exposure — the token dies with the process. |
| T-02-29 | Denial of Service | `open()` throwing on a headless machine, in WSL without interop, or with no registered default browser — killing the server the user asked for | medium | mitigate | The `open` call is wrapped in its own try/catch; a failure prints 02-UI-SPEC.md's "Could not open your browser automatically" copy plus the manual URL, and the server keeps serving. Losing the browser must never lose the session. |
| T-02-30 | Information Disclosure | The Fastify request logger (or an unhandled error dump) printing the `?t=` query string on the initial page load | medium | mitigate | The logger is quiet by default (Plan 04, T-02-20); error paths print only 02-UI-SPEC.md's static copy plus an error message, never the URL or a full request dump. |
| T-02-31 | Denial of Service | An explicit `--port <n>` colliding with a bound port, crashing with a raw stack trace and no guidance | low | mitigate | `EADDRINUSE` is caught and mapped to 02-UI-SPEC.md's port-in-use copy (problem, then next step) with exit code 1 and no banner. The default path (`port: 0`) cannot collide at all (D-02). |
