<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Schema/current value data to DOM | Descriptions, enum prose, and config values render in browser UI. |
| Browser form state to save API | User edits become a candidate JSON object sent to PUT /api/configs/:id. |
| Client validation to server validation | Browser validation is helpful but not authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-16 | Tampering | ConfigEditor save pipeline | high | mitigate | Save candidate must patch raw.project clone and never use effective tree reconstruction. |
| T-03-17 | Information Disclosure | ValidationSummary | medium | mitigate | Render Ajv path/keyword/static messages only; do not render offending values from server errors. |
| T-03-18 | Tampering | EnumCombobox | medium | mitigate | Filter enum list but never permit arbitrary free-text enum values. |
| T-03-19 | Cross-Site Scripting | FieldCard/Unknown values | high | mitigate | Render descriptions/options/current values as text nodes; no dangerous HTML API. |
</threat_model>
