## Trust Boundaries
| Boundary | Description |
|---|---|
| catalog evidence → specialized metadata | Incorrect metadata could permit invalid config values or misrepresent runtime behavior. |
| effective/load data → project draft | Inherited data must not be written into global/canonical layers or strip unknown values. |
| secret value → component state/DOM | Revealed content is sensitive and must not propagate to logs, clipboard, or persistent state. |
